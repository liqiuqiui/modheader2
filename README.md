# ModHeader V2

一个浏览器扩展，用来在浏览网页时实时修改 HTTP 请求和响应：改 Header、改 CSP、改 Cookie、把请求重定向到别的地址。所有修改都组织在「配置（Profile）」里，可以随时切换整套规则。

## 能做什么

| 修改类型   | 说明                                                                        |
| ---------- | --------------------------------------------------------------------------- |
| 请求头     | 添加 / 覆盖 / 追加请求 Header，支持覆盖、追加、逗号追加三种模式，可发送空值 |
| 响应头     | 修改服务端返回的 Header，可与请求头一键互转                                 |
| CSP        | 逐条编辑 Content-Security-Policy 指令，调整页面的安全策略                   |
| Cookies    | 覆盖请求携带的 Cookie                                                       |
| URL 重定向 | 用正则匹配 URL 并替换到目标地址，支持 `$1` 等捕获组                         |

每条规则都可单独启用/禁用、加注释、克隆、隐藏敏感值；Header 名称提供常用预设联想。

## 控制修改的作用范围

修改可以只在满足条件时生效，条件支持「包含」与「排除」两种模式：

- URL 匹配模式、URL 正则
- Tab、Tab 组、窗口
- 资源类型、请求方法
- 发起域名、请求域名
- 自动过期时间（到点后规则自动失效）

不添加任何过滤器时，修改作用于全部请求。

## 多套配置（Profile）

- 每个 Profile 保存一整套规则，可新建、克隆、重命名、拖拽排序、删除，切换后立即生效
- 用主题色区分不同 Profile，支持临时暂停当前配置
- 支持导入 / 导出 JSON、复制到剪贴板，便于备份与分享
- 支持撤销 / 重做

## 使用体验

- 弹窗与独立设置页两种界面，功能一致
- 全局搜索规则、拖拽排序过滤器、分组批量启用/禁用
- 扩展图标角标显示当前生效的修改条数
- 右键菜单可快速暂停 / 恢复当前配置
- 中英文界面，语言选择自动保存

## 构建与安装

需要 Node 22+ 与 pnpm。

```bash
pnpm install
pnpm dev    # 开发模式，端口 3003
pnpm build  # 构建到 .output/chrome-mv3
```

在 `chrome://extensions` 开启开发者模式，加载 `.output/chrome-mv3` 目录即可。

## 开发

基于 WXT + React 19 + TypeScript + Zustand，规则通过 `declarativeNetRequest` 下发；测试基线 26 个文件 / 159 个用例，CI 会执行 lint、格式检查、类型检查、测试与构建。
